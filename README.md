# PLP Python Week 4 Lab: Grades, Eligibility & Smart Decisions

## Files Included
* **welcome.py**: Demonstrates writing a function that accepts a parameter and returns a formatted greeting string.
* **toolbox.py**: Contains utility functions showcasing parameters, return values, and default arguments for handling data calculations.

## Reflection
Writing the toolbox functions with default parameter values was the most challenging part because it required careful attention to how positional arguments and default values interact. Ensuring the logic correctly handled both custom inputs and fallback defaults without syntax or logical errors took extra thought.
